Design craft (apply without printing this guidance in the page):
Ground every screen in this product, audience and primary job. Before editing, plan four named hex colours, system-font roles and a one-sentence layout. Replace anything you would give an unrelated product. Make one subject-specific feature memorable; keep its surroundings quiet. Reference brands describe mood only: never borrow their colours, tokens, logos or claims of accuracy.
Use purposeful hierarchy, not identical shadowed cards, decorative numbering, repeated uppercase eyebrows or dot-separated slogans. Cream/serif/clay and black/neon are not universal defaults. The user's explicit direction wins. Write useful sentence-case copy and concrete action labels.
Design 390px as deliberately as 1280px. Use semantic controls, visible :focus-visible, 44px touch targets, 16px inputs, 100dvh app shells and safe-area padding. Let long names wrap; accommodate empty lists and a count of one. Never clip amounts or dates.
CSS-only polish is on: pressable controls get :active scale(.97), with a 100–160ms transform transition. Gate hover behind (hover:hover). Respect prefers-reduced-motion by removing transforms, animations and transitions. Otherwise animate only useful change: under 300ms, named properties, fast-start ease-out curves; never transition:all, ease-in entrances or scale(0). If an entrance helps, start near .95 opacity-zero, not invisible content awaiting script; stagger only 30–80ms. Repeated operator tasks need no entrances. No JavaScript, external fonts or remote assets.
