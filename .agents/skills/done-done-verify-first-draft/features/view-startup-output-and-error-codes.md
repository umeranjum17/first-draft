# View startup output and error codes

Part of the first-draft verification map. Source: `src/cli.mjs`.

## How to get to it (user POV)

Run the view command in a shell.

## Driving it

Harness: A shell runs the CLI and curl for the url. A browser tool opens the url and each #/o/<n> route for screenshots.

1. Launch the app as SKILL.md says and wait until it is ready.
2. First-draft-axi view <tmp>/sign-in.html --port 0, then first-draft-axi view <missing-path> to see the NO_OPTIONS JSON error.
3. Capture: save the output and exit status to $DONE_DONE_EVIDENCE_ROOT/view-startup-output-and-error-codes.txt, as SKILL.md's Evidence section says.
4. Stop what you started.

The drive changes no repo file: note findings in the run's report; after the drive, run done-done maintain to see what drifted, then fix the skill.
