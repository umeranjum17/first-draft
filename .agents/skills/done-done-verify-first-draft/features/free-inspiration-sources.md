# Free inspiration sources: search first, capture only what is permitted, keep every refusal as a link

Sources: `src/reference-search.mjs`, `src/reference-sources.mjs`, `src/reference-apps.mjs`, `src/reference-network.mjs`, `src/reference-capture.mjs`, `src/reference-terms.mjs`, `src/cli.mjs`, `src/view.mjs`, `src/view/app.js`, `src/view/view.css`, `journeys/references.mjs`, `docs/inspiration.md`.

## Drive

1. Deterministic, no network and no model: `npm run build && node --test test/inspiration-sources.test.mjs`. The local fixture origin serves the open-web results, the Hacker News JSON and the terms pages, and refuses the subreddits through its own `robots.txt`; a stand-in `adb` answers `devices`/`resolve-activity`/`am start`/`exec-out screencap` with a real PNG. Assertions: two queries planned from the brief and tried on the web and Hacker News, three subreddit searches recorded as refused with their reason, one page captured through the robots/terms path with two shots at 390 and 1280, a restrictive terms page and a page with no terms kept as `link-only` with their description and reason, the emulator app captured as `internal_reference_only` with two screens and no URL, `--app` without `--inspiration` refused, the printed `inspiration` summary counts, the `.sources.json` sidecar, and the view serving the sources panel JSON plus `/inspiration/<n>/<i>/<j>` as `image/png`.
2. Real run (needs an installed signed-in model route, since the search queries and every terms review are model calls): `first-draft-axi make "<a product brief, mobile if you will also use --app>" --options 1 --no-critic --inspiration [--app <apk-or-package> --device <serial>] --out <out.html>`. Read the make JSON `inspiration` block and the `<out.html>.sources.json` sidecar: `searches` must name where each query was tried and every refusal with its reason, `sources` must hold captured entries with a terms URL, permission note and URL plus `link-only` entries that still carry their URL, description and why.
3. Mobile part: on a task-owned emulator only (`adb -s <your serial>`, started under the memory gate, killed after), pass `--app <apk>` for an app you may install (a freely downloadable open-source APK is the honest choice) or a package already on that emulator. Read the entry: `package`, `device`, `internal_reference_only: true`, two real screenshots whose dimensions match the device. Without an emulator or `adb`, the same command must refuse with that reason in `why` and still write the page and its sources list.
4. Sealed viewer proof, nonpaid: retain the real `<out.html>` with its `.refs.json`/`.competitors.json`/`.sources.json` sidecars, then `FD_REFERENCE_SOURCE=<out.html> done-done run references`. With the sources sidecar the journey also writes four `sources-<width>-<theme>.png` frames (390/1280 × light/dark) asserting the section exists, one card per captured source, every capture decoded, the link-only and refused-search lists complete, no horizontal overflow, and the whole section inside the visible panel once scrolled to its top.
5. The dated list: open `docs/inspiration.md` at 390 and 1280 in light and dark (GitHub render or the local Markdown layout) and check every named source has its URL, what it is good for and a terms note with the checked date. `docs/guide.md#free-inspiration-sources-and-the-sources-list` and the README reference row link it.
6. Open every PNG before retaining it: each captured source shows its name, its own host, its permission note and its captures without overlap or clipped text; the link-only list stays visible with a description and a reason each. A refusal frame is not evidence that a site refused; the JSON reason is.

## Boundaries

The search is free and bounded: two planned queries over DuckDuckGo's HTML endpoint and Hacker News' public Algolia API, plus one search per designer subreddit through the same robots-checking network; a query that a site refuses is recorded, never retried past the cap. Capture is the existing anonymous path unchanged (public DNS pinned, robots + terms review, no cookies/query strings/custom ports/logins/challenges, 32 requests, 2 MB/resource, 8 MB total, 60 s/capture, at most six pages per run); there is no new scraper and no bypass. The terms review is a model assessment, not legal advice, and most real galleries will be refused: that is the intended result, and the description plus link is the whole output for them. Emulator capture never starts an emulator, never touches a serial it was not given, runs one adb call at a time with a deadline, and its screenshots are internal reference only, never embedded in a generated page. Nothing here proves live policy correctness or live internet reachability, and the emulator step is unproven whenever the environment has no emulator attached.
