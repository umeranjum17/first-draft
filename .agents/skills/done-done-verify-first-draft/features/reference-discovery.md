## Drive

1. Run `node --test test/reference-discovery.test.mjs test/public-references.test.mjs` after building. These are public CLI/integration journeys, not unit tests. The local provider/native-CLI fixture identifies Vercel from `make it like Vercel`; the local brand-site fixture supplies explicit screenshot permission. Actual Chromium captures 390×844 and 1280×800 PNGs, caches them with sources, then make/refine/viewer refinement use native image inputs and the observed visual brief. Check cached reuse without site requests, source-linked PNG endpoints, preserved portable sidecars, stale-sidecar removal, anonymous UA/no cookies/auth, and robots/terms/login/redirect/size/timeout refusals. Fixture mode admits exactly one explicitly named HTTP loopback origin, never arbitrary private hosts. CI does not visit brand sites or spend.
2. With explicit permission for a bounded real-model run, retain normal HOME/installed sign-in; isolate only FIRST_DRAFT_HOME. Configure `byokit:claude` / `claude-opus-5-5`. Drive real make with a permissioned public source via `--like <https-url>`. If using the owned `journeys/fixtures/reference-site.mjs` as a deterministic source, set FIRST_DRAFT_TEST_REF_ORIGIN to its exact loopback origin and state clearly that it is not the real Vercel site. Save make JSON, exported HTML/sidecar, source requests and sources.json. Require native capture inputs, visual-language observations, successful render check, no truncation, chosen model/route, and no copied source assets/text/pixels in the HTML. Stop on subscription limits; never enable extra credits or use key/gateway Claude.
3. Preserve the real generated HTML and sidecar, then commit the candidate including capture recipe. On that clean final head run `FD_REFERENCE_SOURCE=<retained-html> done-done run references` with default done-done HOME. This is a genuine nonpaid recapture of the real CLI viewer: four whole-viewport shots (390/1280 × light/dark), app navigation/option/result and refs in frame, no text crops. `steps.json` binds the candidate HEAD and explains retained source/local-fixture limitations; support/source.json records source hashes, support/metrics.json records viewport/theme, decoded images, links and scroll-container counts.
4. Open every PNG before retaining it. Check source thumbnails, Source/Permission links, generated option and navigation are visible without overlaps, horizontal overflow, clipped controls or internal paths. Capture claims should be only that the viewer displays the two cached references beside the option, one claim per capture. No custom animation changed; ordinary source-image links use native navigation.
5. Use `done-done check`/`receipt` on only that sealed run's whole-product PNGs, with a narrow literal outcome. A test pass, fixture response, model report, or steps file does not establish visual/model/legal accuracy. Never rewrite a failed/inconclusive judge as PASS. Post an Evidence card to the exact board authorized by firstmate, with the real product captures, not JSON/logs. Stop browsers/view processes started by this drive and remove their task-owned profiles.

## Boundaries

Discovery-only output is an unverified candidate, not a visit or permission. Public fetches pin public DNS and recheck redirect targets/robots; anonymous GET only, no cookies/query strings/custom ports/login/challenges. Limits: 32 requests, 2 MB/resource (64 KB robots), 8 MB total, 10 seconds/request, 60 seconds/capture. Terms review requires a same-origin public terms/licence link and an exact supporting permission quote; model assessment is not legal advice. Unclear/restrictive terms refuse capture; many public brands will not qualify, and no bypass is offered. References cache for 24h per project. Scripts/frames/cross-origin assets are disabled, so screenshots are first-viewport/static approximations; the brief records actual computed styles and omissions, CSS motion declarations only. The source screenshots are model inputs and viewer references, never embedded design assets. Existing local --ref still works; --no-references disables automatic online gathering. Do not claim that the local fixture proves live Vercel access, that a visual judge proves policy correctness, or that nonpaid recapture performs new generation.
