# Reference-grounded screen benchmark

1. Run `node --test test/inspiration-sources.test.mjs`: the real CLI searches one loopback fixture, respects robots/terms/access gates, reuses the reference cache, imports current/candidate/reference/counterexample images and sends actual rasters through the published subscription adapter to a local deterministic CLI stand-in. Every target gets seven reference-aware axes; missing positive references fails with a retained unscored sheet. No external network or real models.
2. Real proof: obtain task-owned current/candidate captures (never an installed personal app) and the owner's permitted references. Write the manifest documented in `docs/benchmark.md`; keep unknown capture dates null and source URLs unknown rather than invented. Counterexamples never become positive references. Run `benchmark --product ... --screen ... --input ... --width 390 --theme dark --out ...`; discovery uses the public policy-checked path, and a hosted independent judge scores every target. For capture-only checks add `--no-discovery --no-judge`; state clearly that this proves assembly, not quality.
3. Capture the retained output without new model calls: `FD_BENCHMARK_SHEET=<sheet.html> DONE_DONE_EVIDENCE_ROOT=<existing-evidence-folder> node journeys/benchmark.mjs` with task-private HOME/XDG/TMPDIR and the real `chrome-devtools-axi` installed on PATH. The journey starts only an isolated browser and a private loopback sheet server, then closes both. It writes `sheet-390-<theme>.png`, `sheet-1280-<theme>.png`, native image-width observations, and `scores-<theme>.png` when scored. Repeat with a matching-theme manifest for light/dark coverage of the new sheet; retain all source captions and refusal reasons. Scroll horizontally to inspect every capture, not just the initial columns. Open every retained screenshot before reporting.

Limits: same CSS display width is not an assertion of original viewport equality; references are never recoloured. Public acquisition in this slice is light HTML only, so a dark run records discovered public pages as unavailable. An unrelated page cannot calibrate chat features: the judge must abstain when no reference pixels support an axis. Null scores, model outages and missing current-screen proof remain explicit; deterministic fixture scores never stand in for live Crewhouse quality scores. No media enters the repository/package.
